# XR Kaigi 2026 表示の仕組み（作業中）

| ページ | 使う場所 |
|---|---|
| `presenter.html` | Macの本体画面（全画面）。「投影画面を選ぶ」でスクリーンに `projector.html` が開く。録画もここから |
| `projector.html` | スクリーン。3D空間に文字が並び、アニメで切り替わる。最初は普通の表紙で、次へ進むと粒になってほどける |
| `aura.html` | Aura の Chrome（発表者ビュー） |
| `index.html` | 参加者のスマホ。「3Dで見る」でプレゼンの空間を回して見られる |
| `index.html?replay=` | 録画の再体験。録画の動画と記録の2つを選ぶと、空間の中で再生する |

一覧ページには載せていない。
